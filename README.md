# SmartApply – AI Resume Analyzer & Job Matcher

SmartApply is an AI-powered resume analyzer and job matching web application built using Python, Flask, NLP, and Sentence Transformers. It helps users analyze their resumes, identify relevant skills, discover missing skills, and find suitable job roles based on their resume content.

## ✨ Features

- Upload resumes in PDF format.
- Extract resume text automatically.
- Identify technical and professional skills.
- Analyze resumes using AI and NLP.
- Match resumes with relevant job roles.
- Calculate job match percentage.
- Identify matching and missing skills.
- Provide suggestions to improve resumes.
- Display ranked job recommendations.
- Simple and responsive user interface.

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Flask
- **AI / NLP:** Sentence Transformers
- **Machine Learning:** Cosine Similarity
- **PDF Processing:** PyMuPDF
- **Data Processing:** NumPy

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd SmartApply
```

### 2. Create a Virtual Environment

```bash
python -m venv .venv
```

### 3. Activate Virtual Environment

**Windows:**

```powershell
.\.venv\Scripts\Activate.ps1
```

### 4. Install Dependencies

```bash
python -m pip install -r requirements.txt
```

### 5. Run the Application

```bash
python app.py
```

Open your browser and visit:

```text
http://127.0.0.1:5000
```

## 🚀 How It Works

1. Upload your resume in PDF format.
2. Enter the job roles you are interested in.
3. SmartApply extracts information from your resume.
4. AI analyzes your skills and experience.
5. The system compares your resume with job profiles.
6. View match scores, missing skills, and recommendations.
